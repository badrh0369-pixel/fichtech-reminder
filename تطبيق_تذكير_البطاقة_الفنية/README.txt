تطبيق تذكير البطاقة الفنية - مشروع Android Studio

الخطوات:
1) ثبّت Android Studio (مجاني) وافتح هذا المجلد: File > Open.
2) انتظر انتهاء Gradle Sync (يحتاج إنترنت أول مرة).
3) Build > Build APK(s).
4) الملف يكون في: app/build/outputs/apk/debug/app-debug.apk
5) انقله إلى الهاتف وثبّته (فعّل "التثبيت من مصادر غير معروفة").
6) عند أول تشغيل: اسمح بالإشعارات وفعّل "المنبهات والتذكيرات".
